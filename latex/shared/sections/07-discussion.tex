\DocSection{Discussion and Limitations}
\label{sec:discussion}

The target in Equation~\eqref{eq:policy-target} has a useful property: with a
uniform reference measure, its modes preserve ordinary expected-return
optimality.  A finite-temperature draw is nevertheless not a classical optimal
policy.  It is a randomized selection rule controlled by \(\beta\) and
\(\mu\).  The resulting spread should not be described as calibrated epistemic
uncertainty about an unknown environment.

Replica exchange corrects neither a misspecified target nor poor finite-run
mixing.  Local state changes can leave high-dimensional policy modes separated
by low-value barriers, a PPO guide can be overconfident in one region, and a
temperature ladder can have a bottleneck near the cold chain.  Exact Hastings
correction guarantees invariance, not useful effective sample size.  Swap rates
on every edge, multiple dispersed chains, policy-coordinate diagnostics, and
explicit nonconvergence decisions are therefore part of the method rather than
optional presentation details.

The two evaluation modes have different claims.  Dynamic programming gives an
exact target but requires the model.  Fixed-tape sample-average inference needs
only a generative simulator, but its finite-\(K\) target differs from the
scientific target and may require many rollouts when \(\beta\) is large.  It is
therefore more accurate to call the overall approach simulator-based planning
than model-free reinforcement learning.  Bounded finite-horizon returns do
permit a nonnegative Poisson estimator of \(\exp(\beta J)\), and hence an exact
pseudo-marginal construction; Appendix~\ref{app:derivations} gives the identity.
Its relative variance can grow prohibitively at the large \(\beta\) values and
return ranges needed here, so an implementation would require a separate
variance-and-mixing gate rather than an unqualified claim of exact practicality.

The direct ELBO avoids exponentiating a noisy value estimate, but its
score-function gradient can have high variance and a factorized variational
family cannot represent correlations between policy modes.  Replicated SMC can
retain a multimodal weighted population, yet it is vulnerable to particle
degeneracy and must copy every memoized assignment and simulator replica during
resampling.

All reported learned policies are stationary in physical state.  This keeps the
output class consistent but prevents any method from representing an action that
depends explicitly on time-to-go.  PPO uses Monte Carlo rather than
generalized-advantage estimates and does not use value clipping.  Discrete SAC
fixes its entropy temperature but uses time-indexed twin critics and replay tuples
for finite-horizon backups.  Double Q-learning likewise uses time-indexed tables,
then forms a stationary output by state--time-visitation-weighted projection.
These are precise implemented variants, not claims of reproducing every
enhancement of the algorithm families.  GridWorld currently uses \(\gamma=1\),
and the guard against unvalidated discounted runs must remain until the gradient
and target semantics are tested.

Finally, GridWorld supports controlled correctness and scaling experiments but
cannot establish broad generality.  Blackjack is a low-cost nonspatial check.
Tireworld would add structured stochastic failure at higher implementation
cost.  Factored concurrent-action and continuous-control domains require new
policy representations and reference measures and are left to future work.
